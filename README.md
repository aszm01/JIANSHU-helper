# 录屏键鼠助手

一个轻量的 Windows 悬浮窗工具，实时可视化展示你的键盘鼠标按键状态，同时记录按键操作日志，方便录屏、教程制作和操作复盘。

## 下载运行

在 [Releases](https://github.com/aszm01/JIANSHU-helper/releases) 页面下载最新的 `录屏键鼠助手.zip`，解压后双击 `录屏键鼠助手.exe` 即可，无需安装。

> 首次运行如被 Windows SmartScreen 拦截，点击「更多信息」→「仍要运行」即可。

## 使用说明

### 悬浮窗

程序启动后屏幕上会出现一个键盘+鼠标的悬浮窗，实时显示：

- **按下的按键**：对应位置亮绿色
- **鼠标左右键、滚轮、侧键**：按下时亮起
- **鼠标位置**：跟随你的鼠标移动

悬浮窗可以拖动到任意位置。

### 录制与导出

- 点悬浮窗上的「开始」按钮开始录制，再点一次停止
- 停止后点「下载」按钮，把按键记录导出为文本文件
- 也可以右键点系统托盘图标，选「下载记录」

### 系统托盘

程序不在任务栏显示，而是缩在屏幕右下角的系统托盘里：

- **左键单击托盘图标**：调出悬浮窗
- **右键托盘图标**：显示菜单（显示悬浮窗、开始/停止录制、下载记录、退出）
- **托盘图标颜色**：灰色 = 未录制，蓝色 = 正在录制
- **点悬浮窗右上角 X**：隐藏悬浮窗（程序继续在后台运行）
- **想彻底退出**：右键托盘图标 →「退出」

### 设置

点悬浮窗上的齿轮图标，会弹出设置面板：

- **背景透明度**：调节悬浮窗白底的透明度，不影响按键指示和键盘线稿
- **鼠标穿透**：开启后除了齿轮按钮外，悬浮窗不拦截鼠标点击，可以直接点到下面的窗口
- **位置固定**：锁定悬浮窗位置，不能拖动

## 系统要求

- Windows 10 / 11（64 位）

## 常见问题

**Q：打开后看不到悬浮窗？**
A：看右下角系统托盘，左键单击托盘图标即可调出。

**Q：按键记录里小键盘数字显示为 `?`？**
A：这是部分键盘驱动（尤其罗技、微软蓝牙鼠标/键盘）上报的扫描码不标准导致的，不影响主键盘记录。

**Q：关闭后程序还在运行？**
A：点 X 只是隐藏到托盘。要彻底退出请右键托盘图标选「退出」。
