# 录屏键鼠助手

一个运行在 Windows 右下角的悬浮窗小工具：**全局监听键盘和鼠标操作**，在键鼠底图上实时高亮显示，并可录制、导出操作记录。

## 功能

- **全局监听**：切到任何软件都能感知按键/鼠标/滚轮操作，无需窗口焦点
- **实时高亮**：右下角悬浮窗，按键即亮即灭，半透明绿色标记
- **录制 / 导出**：把操作序列导出为 UTF-8 文本（按下/松开/延迟/鼠标坐标/滚轮方向）
- **齿轮设置**：背景透明度、鼠标穿透、位置固定
- **热键**：`Alt + *` 或 `Ctrl + Alt + R` 快速切换录制
- **开关状态**：CapsLock / NumLock 显示真实开关状态
- **分辨率自适应**：窗口宽度 = 屏幕宽度 1/4，元素百分比布局，DPI 感知不模糊

## 使用

### 下载运行

从 [Releases](../../releases) 下载 `录屏键鼠助手.exe`，双击运行即可，无需安装 Python。

### 源码运行

需要 Python 3.9+，安装依赖：

```bash
pip install pynput pillow resvg-py
```

运行：

```bash
python keyboard_mouse_viz.py
```

### 操作说明

| 操作 | 方法 |
|------|------|
| 开始 / 录制 | 点击「开始」按钮开始（变绿显示「录制」），再点一次停止；停止后出现「下载」 |
| 下载 / 已导出 | 点击「下载」把记录导出到程序所在目录，文件名为 `键鼠记录_日期_时间.txt` |
| 打开设置 | 点击鼠标背部齿轮图标 |
| 拖动位置 | 按住窗口空白处（非按钮区）移动（未启用"位置固定"时） |
| 关闭 | 点击右上角 X |

### 设置项（齿轮）

- **背景透明度**：拖动滑块调整悬浮窗背景（含 3px 边框）透明度，实时生效；线稿、按键标记、文字、按钮恒不透明
- **鼠标穿透**：开启后除齿轮外，窗口其余区域全部点击穿透
- **位置固定**：开启后窗口不可拖动

## 分辨率适配

- 窗口宽度恒为屏幕宽度的 1/4，高度按底图比例
- 所有按键热区、按钮、字体均为百分比/相对布局，随窗口等比缩放
- 程序启用 DPI 感知，在高缩放（150%/200%）下不模糊
- 运行中切换分辨率需重启程序生效
