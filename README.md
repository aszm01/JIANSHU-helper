# 键鼠操作可视化记录器

一个运行在 Windows 右下角的悬浮窗小工具：**全局监听键盘和鼠标操作**，在键盘底图上实时显示按下的按键（半透明绿色高亮），并可将操作记录导出为文本。

> 本项目由网页版键鼠记录器改造而来，用 Python 原生实现，摆脱浏览器限制：切到任何软件都能感知按键，无需窗口焦点。

## 功能特性

- 全局键鼠监听：切到任何应用都能实时显示按键/鼠标/滚轮操作
- 右下角悬浮窗：键盘鼠标底图 + 半透明绿色高亮，按键即亮即灭，零延迟（预合成点亮图）
- 半透明无点阵：高亮为真半透明合成，键帽纹理透出
- 开始/停止录制 + 导出记录：导出为文本文件（按下/松开/延迟/鼠标坐标/滚轮方向），UTF-8 编码
- 支持热键：`Alt + *` 或 `Ctrl + Alt + R` 切换录制
- CapsLock / NumLock 显示真实开关状态（每 300ms 读取系统状态）
- 任意分辨率自适应：窗口宽度 = 屏幕宽度 1/4，全部元素百分比布局，DPI 感知不模糊
- 右上角正方形 X 关闭按钮（Windows 风格，悬停红底白 X），瞬时关闭

## 快速开始

### 方式一：直接下载 exe

从 [Releases](../../releases) 下载 `录屏键鼠助手.exe`，双击运行即可，无需安装 Python。

### 方式二：源码运行

需要 Python 3.9+，安装依赖：

```bash
pip install pynput pillow
```

运行：

```bash
python keyboard_mouse_viz.py
```

## 打包为 exe

```bash
pip install pyinstaller
python -m PyInstaller --onefile --noconsole --name "录屏键鼠助手" --add-data "初始.png;." keyboard_mouse_viz.py --clean
```

产物在 `dist/录屏键鼠助手.exe`（也可直接用仓库里的 `键鼠可视化记录器.spec` 复现构建）。

## 使用说明

- **开始 / 录制**：点击右上角红色「开始」按钮开始录制（变绿并显示「录制」），再点一次停止；停止后出现蓝色「下载」按钮
- **下载 / 已导出**：点击「下载」将记录导出到 exe（或脚本）所在目录，文件名为 `键鼠记录_日期_时间.txt`
- **热键**：`Alt + *` 或 `Ctrl + Alt + R` 快速切换录制
- **拖动**：按住窗口空白处（非按钮区域）可移动悬浮窗位置
- **关闭**：点击右上角 X

导出文件示例：

```
键鼠操作记录
==================================================
记录时间: 2026-09-27 16:46:36
操作总数: 8
==================================================
1. 按下：A
2. 延迟：0ms
3. 按下：小键盘1
4. 延迟：120ms
5. 松开：小键盘1
6. 延迟：80ms
7. 滚轮上
8. 延迟：45ms
```

## 分辨率适配

- 窗口宽度恒为屏幕宽度的 1/4，高度按底图比例
- 所有按键热区、按钮、字体均为百分比/相对布局，随窗口等比缩放
- 程序启用 `SetProcessDpiAwareness(2)`，在 150%/200% DPI 缩放下按物理像素渲染，不会模糊
- 已实测 1366×768 / 1920×1080 / 2560×1440 / 3840×2160 均正常
- 注意：运行中切换分辨率需重启程序生效
